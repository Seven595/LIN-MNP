# Figures

- `manuscript/` — framework, attribution, and benchmark-composite builders.
- `spatial_maps/` — spot-level cSCC, HEST, and STImage maps.

All builders read roots from `lin_mnp.paths` and write below
`$LIN_MNP_RESULTS_ROOT/figures/` by default. See
[`REPRODUCTION.md`](../REPRODUCTION.md#3-figure-workflows) for exact commands
and required artifacts.
